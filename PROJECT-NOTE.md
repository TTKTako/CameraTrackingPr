# Multi-Camera AI Detect Rig

## Project Description

This project is the python application to open the camera (0 to n) amount and detect the pose of the people in camera. In case there's more than 1 people in frame detect the closest one.

**Note:** Pose output need to match and cover all of the vrm format rig.

## Key Feature
- Multiple Camera with difference angle
- show all of the camera in the screen and show the rig over the people in photo
- can upload vdo to loop get the pose
